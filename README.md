# SQL Practice and Learning

This repository contains my SQL practice queries and exercises, covering fundamental to advanced SQL concepts using SQL Server.

Topics covered include:
- Basic SQL queries (SELECT, DISTINCT, WHERE, ORDER BY)
- Filtering and sorting data
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING clauses
- Data manipulation (INSERT, UPDATE, DELETE)
- Table creation and modification (CREATE, ALTER, DROP)
- SQL Joins (INNER, LEFT, RIGHT, FULL)
- Set operators (UNION, UNION ALL, INTERSECT, EXCEPT)
- String and mathematical functions
- Date and time functions
- NULL handling (IS NULL, COALESCE, NULLIF)
- Conditional expressions (CASE WHEN)
- Common Table Expressions (CTEs)
- Window functions and analytical queries

**Purpose:** To develop practical SQL skills in data extraction, manipulation, transformation, and analysis as part of my learning journey in data analytics and data science.
